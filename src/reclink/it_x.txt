Privacy and rules|||Privacy e regole
Received Remote ID data lives in memory only. It is never written to flash and never appears in the log.|||I dati Remote ID ricevuti vivono solo in memoria. Non vengono mai scritti nella flash e non compaiono mai nel log.
Operator ID, free-text, operator location and authentication data are thrown away without being read. The only identifying value kept is an aircraft's ID, and only so you can ignore your own.|||L'ID operatore, il testo libero, la posizione dell'operatore e i dati di autenticazione vengono scartati senza essere letti. L'unico valore identificativo conservato è l'ID dell'aereo, e solo per poter ignorare il tuo.
Data leaves the board only through the Remote ID tab, while the configurator is open.|||I dati lasciano la scheda solo attraverso la scheda Remote ID, mentre il configuratore è aperto.
RecLink makes no claim about regulation.
