# FPVitt.github.io

The website at **https://fpvitt.github.io/**. A landing page lists the projects; each project lives in its own folder.

| Path | What |
|---|---|
| `index.html` | Landing page (generated) |
| `RecLink/` | The RecLink site: user guides (EN/IT), the board page, firmware installer, PDFs (generated; URL stays `/RecLink/`) |
| `src/reclink/` | Sources and build scripts for the RecLink section |
| `sitemap.xml`, `robots.txt` | Generated by the build |

Firmware: <https://github.com/FPVitt/RecLink>

## Build

```sh
python -m venv .venv && . .venv/bin/activate
pip install beautifulsoup4 pillow gerbonara shapely trimesh numpy   # last four only for regenerating the 3D board assets
cd src/reclink
python build_web.py
```

`build_web.py` writes `RecLink/`, `index.html`, `sitemap.xml` and `robots.txt` at the repo root. Commit the result: GitHub Pages serves the repo as it is.

The PDFs in `RecLink/pdf/` come from `build2.py` / `render.py` (headless Chromium via Playwright) and are copied in by hand.

## New firmware release

The installer (`RecLink/flash/`) serves the firmware images from this repo, because GitHub release downloads cannot be fetched by the browser from another site:

1. Build and merge the images, copy the `.bin` files into `RecLink/flash/`.
2. Update the version in `RecLink/flash/manifest-*.json` and in `src/reclink/build_web.py` (`FW`), then rebuild.

## Adding a project

Add an entry to `projects` in `build_home()` (`src/reclink/build_web.py`) and put the project's pages in a new top-level folder.

## Analytics (GoatCounter)

Anonymous, cookieless statistics. Set `GC_CODE` in `src/reclink/build_web.py` to your GoatCounter site code (`https://<code>.goatcounter.com`) and rebuild; with an empty code nothing is loaded. Visitors with Do Not Track on are skipped. When active, a one-line notice is added to the page footers.

Custom events from the installer (shown under *Events* in GoatCounter): `flash/board/<board>`, `flash/method/<board>/<usb|ota>`, `flash/version/<tag>`, `flash/download/<asset>`, `flash/connect/<board>` (Connect button), `flash/dialog-opened/<board>` (a serial port was picked) and `flash/dialog-closed/<board>/<finished|not-finished>` (the last one reads an internal property of ESP Web Tools 10, so re-check it after a library bump).
